## About This Repository

This repository documents my learning journey throughout the 16-week Cloud to Solutions Accelerator programme using the **FinTrust** banking case study.

The portfolio showcases practical work completed throughout the programme, covering AWS cloud architecture, Python development, SQL, data engineering, networking, security, APIs, serverless computing, event-driven architecture, analytics, streaming, machine learning, cost management, governance, migration planning, resilience and supporting technical documentation.

Each completed week builds on the previous one, demonstrating the progression from cloud fundamentals toward designing and implementing production-inspired cloud solutions.

The portfolio distinguishes between technologies that were **implemented**, **configured**, **designed**, **explored**, and **evaluated**. AWS services are not presented as deployed unless there is evidence that they were actually provisioned and used.
