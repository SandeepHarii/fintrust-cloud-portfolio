# Week 3 — AWS Storage & Python Development

## Overview

Week 3 focused on AWS storage services and intermediate Python development using the FinTrust banking case study. Morning (AM) sessions explored Amazon S3, storage security, CloudFront, hybrid storage solutions, and AWS storage architecture, while afternoon (PM) sessions strengthened Python programming through functions, modules, file input/output, and error handling.

---

## What I Learned This Week

### AWS (AM Sessions)

* Explored Amazon S3 architecture, object storage, and storage concepts.
* Learnt how to secure Amazon S3 using bucket policies and access control.
* Hosted static websites using Amazon S3 and Amazon CloudFront.
* Explored hybrid cloud storage solutions with the AWS Snow Family.
* Applied AWS storage architecture principles to design scalable and reliable storage solutions.

### Python (PM Sessions)

* Developed reusable Python functions and organised code into modules.
* Utilised Python's Standard Library to build more maintainable applications.
* Performed file input and output (File I/O) operations for reading and writing data.
* Implemented exception handling using `try`, `except`, `else`, and `finally`.
* Applied logging techniques to improve application monitoring and debugging.
* Built reusable utility modules to support multiple Python applications.
